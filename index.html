Connect to your data

Job data lives in a private repo. This page reads it directly from the GitHub API using a token you provide. Nothing is sent anywhere else — the token stays in this browser's local storage and every request goes straight to api.github.com.

How to make a token with the least possible power
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your data repo alone.
  3. Permissions: Contents → Read-only. Nothing else. Not metadata-write, not actions, not issues.
  4. Expiry: 90 days. Put a calendar reminder to rotate it.

A token in browser storage is readable by anything that can run script on this origin. That is an acceptable trade only because this one is read-only and scoped to a single private repo. Never paste a classic token here, and never paste one with write access.
